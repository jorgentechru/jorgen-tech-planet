# JORGEN TECH PLANET

Самостоятельная редактируемая версия интерактивного проекта WORLD//LAB с новым брендом. Это продолжение исходного приложения: сохранены его SVG-остров, камера, маршруты и четыре сценария. Используется исходный стек: HTML, CSS, нативные JavaScript ES-модули и SVG. Сторонние пакеты не нужны. Backend отсутствует.

## Запуск на Windows — пошагово

1. Установите **Visual Studio Code** и **Python 3** с сайта python.org. В установщике Python включите **Add Python to PATH**.
2. Распакуйте ZIP в удобную папку, например `C:\Projects\jorgen-tech-planet`.
3. В VS Code выберите **File → Open Folder…** и откройте распакованную папку.
4. Откройте терминал: **Terminal → New Terminal**.
5. Проверьте Python: `py --version`. Если команда `py` недоступна, попробуйте `python --version`.
6. Запустите сервер: `py -m http.server 8000 --directory dist` (либо `python -m http.server 8000 --directory dist`).
7. Перейдите в браузере по адресу `http://localhost:8000`.
8. Остановите сервер сочетанием `Ctrl+C` в терминале.

Установка JavaScript-зависимостей не требуется. Файл `package.json` содержит короткое описание и команды для удобства. Для этого статического сайта сборка перед публикацией не нужна. Если в Windows `py` настроен, `npm start` запускает Python-сервер; иначе выполните команду из шага 6.

## Перед публикацией: заполните контакты

Откройте `dist/author.js` и укажите настоящие данные автора в одном месте:

```js
export const author={
  name:'Ваше имя', role:'Веб-разработчик',
  email:'адрес@example.com',
  telegram:'https://t.me/ваш_ник',
  github:'https://github.com/ваш_аккаунт',
  portfolio:''
};
```

Для Telegram и GitHub вставляйте полные ссылки с `https://`. Не оставляйте шаблонное имя перед публичной публикацией. Пока поля пустые, сайт показывает инструкцию к конфигурации, а не вымышленные адреса. Текст об опыте и технологиях редактируется в обработчике `#about` файла `dist/app.js`.

## Что есть в приложении

- **Планета:** перетаскивание и масштабирование SVG-острова, мультитач-жест, выбор четырёх пространств, переход к разделам, кнопки, клавиатура и режим уменьшенного движения.
- **Automotive Hub:** класс автомобиля, зоны машины и каталог услуг, расчёт суммы и времени, проверка занятого интервала, демозапись.
- **Commerce Hub:** каталог концепт-товаров, поиск, категории, сортировка, избранное, корзина с количеством, карточки и демозаказ.
- **Creator Studio:** галерея и фильтры концептуальных проектов, описания, локальный конструктор брифа.
- **Control Center:** список Automotive-записей и заказов, изменение статусов, сводка и подтверждаемый сброс.

Данные изолированы в `sessionStorage` браузерной вкладки и могут пережить восстановление вкладки. Они не синхронизируются между браузерами или людьми. Создание записи и заказа не отправляет сведения наружу и не принимает оплату. Цены и продукты — демонстрационные.

## Проверки

- `npm test` или `node tests/domain.mjs` — проверка цены, коэффициента SUV, пустой записи, конфликтов времени, корзины, заказа и сброса.
- `npm run check` — синтаксическая проверка JavaScript через Node.js.
- `npm start` — локальный сервер через Python; если команда не находит Python, используйте `py -m http.server 8000 --directory dist`.

## Публикация на GitHub

1. Создайте пустой репозиторий GitHub, например `jorgen-tech-planet`. Не добавляйте сгенерированные GitHub README/License, чтобы избежать конфликта при первом push.
2. В терминале VS Code из корня папки задайте имя и email для Git, если Git ещё не настроен: `git config --global user.name "Ваше имя"` и `git config --global user.email "ваш email"`.
3. Выполните команды, заменив адрес на URL своего репозитория:

```powershell
git init
git add .
git commit -m "Initial JORGEN TECH PLANET project"
git branch -M main
git remote add origin https://github.com/ВАШ-АККАУНТ/jorgen-tech-planet.git
git push -u origin main
```

4. Для следующих изменений: `git add .`, `git commit -m "Краткое описание"`, `git push`.
5. Если GitHub запросит вход, авторизуйтесь через браузер или Git Credential Manager. Не сохраняйте токены в исходниках.

## Размещение сайта

Для первого бесплатного статического размещения подходят **GitHub Pages**, **Cloudflare Pages** или **Netlify**. Подключите репозиторий и задайте корневую папку публикации `dist`; команда сборки не нужна. На GitHub Pages выберите `Settings → Pages → Deploy from a branch`, ветку `main`, папку `/dist` (если интерфейс предлагает её) либо вынесите статические файлы в корень отдельным deployment workflow. Cloudflare Pages/Netlify умеют публиковать непосредственно каталог `dist`.

Позже подключите домен в панели выбранного хостинга и настройте предложенные им DNS-записи. Hash-маршруты `#/automotive` работают на статическом хостинге без серверных rewrite-правил. HTTPS обычно выдаёт хостинг автоматически. Для изменений сайта достаточно снова сделать `git push`.

## Python backend в будущем

Для backend понадобятся согласованные API-контракты, серверная валидация цены и доступности слотов, идентификатор и срок жизни демосессии, изоляция записей по сессии, очистка истёкших записей, обработка ошибок и ограничение частоты запросов. FastAPI — кандидат, но это отдельный проектный выбор. Хранить заявки только в браузере недостаточно для серверной изоляции или общей панели. Ключи и секреты должны оставаться только в переменных окружения сервера; фронтенд не должен получать секреты.


### Фото автора и Email

- Поместите собственную фотографию лица в `dist/portrait.jpg` (желательно квадратное фото, JPG). Она появится небольшим круглым портретом над заголовком главной страницы. Пока фотографии нет, блок скрыт автоматически.
- В `dist/author.js` измените `author.email`, если требуется. Основная кнопка «Скопировать почту» работает без почтового приложения.

### Обновлённая главная и контакты

- На главной справа поверх карты есть заметный блок: чем я занимаюсь, почта и кнопки связи. На телефоне предложение располагается **перед картой**, чтобы его не пришлось искать.
- Кнопки **«Связаться»** в шапке и **«Написать разработчику»** внизу открывают окно контактов из любого раздела.
- В окне **«Обо мне»** почта и кнопки находятся в отдельной карточке и больше не смешиваются с текстом.
- Основное действие — **«Скопировать почту»**. Оно не открывает пустую вкладку. Отправку письма пользователь выполняет в своём почтовом сервисе.
- На страницах всех четырёх разделов внизу показывается предложение обсудить новый проект.
- Главная, навигация, карта и карточки разделов переведены преимущественно на русский. Новые компоненты находятся в `dist/index.html`, `dist/app.js`, `dist/author.js` и `dist/contact-redesign.css`.

## Процедурный рельеф острова

В `dist/world.js` SVG-сцена включает декоративный природный слой, сформированный детерминированным клеточным автоматом. Клетки сглаживаются соседскими правилами, край получает песочный оттенок, внутренние участки — вариации травяного цвета. Seed зафиксирован: остров повторяется одинаково при каждом запуске. Генератор рисует только текстуру внутри исходного контура; здания и дороги остаются в заданных координатах. Это лёгкая SVG-геометрия, не игровой движок и не случайная перестройка карты.
